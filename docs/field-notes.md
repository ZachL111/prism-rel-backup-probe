# Field Notes

The useful part of this repository is the small rule set around budget pressure and recovery gap.

The domain cases cover `budget pressure`, `failure width`, `recovery gap`, and `runbook drift`. They sit beside the smaller starter fixture so the project has both a compact scoring check and a domain-flavored review check.

`stress` is the strongest case at 246 on `failure width`. `stale` is the cautious anchor at 152 on `budget pressure`.

The extra check gives the repository a behavior path that can fail for a domain reason, not only a syntax reason.
